# Basset placement packet

## Project

**Zeke Authorize by Corgi-verse** — phone-held approval for agent actions, with an open protocol that can connect Zeke and ChatGPT Dots clients.

The product promise is: **Ask in any integrated chat. Review on your phone. Approve one exact action.**

The phone owns the private approval key. Chats make requests. Executors enforce current approval at the side-effect boundary. QR codes carry short-lived review links, never agent credentials or execution authority. Zeke supplies a custom phone design; a Dots platform integration can provide a cleaner native presentation using the same semantics.

## What Basset can place now

- A private placement/demo package or an experimental public open-source reference, after publication through the project owner’s release process.
- A runnable single-owner broker, browser console, camera-to-passkey phone web flow, native signature API, executor adapter and sandbox demonstration.
- A detailed native iOS/Android phone specification and original key-module source, clearly labeled uncompiled and not a complete app.
- A proposal for official Zeke/Dots integration with concrete acceptance gates and a coverage matrix.

The pitch must describe simulated phone signature tests accurately. Do not market this package as a production security product, a shipping native app, a verified hardware-backed remote identity, an existing OpenAI integration, or an audited universal authorization layer.

## Candidate placements

1. Zeke’s own chat and selected-document workflow: strongest first controlled pilot because both request and execution boundaries can be integrated by the project owner.
2. Open-source agent/tool frameworks: a connector or middleware example demonstrating exact-action gates and the phone approval protocol.
3. A supported ChatGPT/Dots connector or platform collaboration: request-card adoption first, followed by platform-owned executor enforcement and native phone UI where access is available.

These are proposed placement categories, not identified contacts, existing agreements, or verified available internal APIs. No outreach, cross-chat messages, repository publication, or deployment was performed in preparing this packet.

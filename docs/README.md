# Dotsys documentation

Dotsys is an experimental documentation and offline-validation package, independent of OpenAI. Start with the path that matches what you want to do.

## Set up a personal System

1. Read the [project overview](../README.md) for the purpose, contents, and current limits.
2. Review the [license](../LICENSE) and [security guidance](../SECURITY.md) before adopting.
3. Use the [setup and operating guide](ADOPTION.md) for the complete prompt. Surface is the default first project; capture, builds, access, and publication require their applicable separate approvals.

The setup prompt describes a supported, approval-gated workflow. This package does not itself create accounts, build Surface, or run a service.

## Try a practical skill

- [Dotsys Skills](../skills/README.md): the Paste Inbox download, use prompt, prerequisites, and limitations. Explicit chat capture is separate from the planned panel/hotkey.

## Understand or check the protocol

- [Protocol specification](../PROTOCOL.md): the normative Dotsys 0.1.0 contract, document types, and security boundaries.
- [Paired handshake walkthrough](PAIRED-HANDSHAKE.md): a worked local hello/response exchange, including declines, duplicates, conflicts, and expiry.
- [Offline verification](../VERIFY.md): requirements, reproducible commands, test coverage, and what the checks cannot establish.
- [Machine-readable documentation index](../llms.txt): schema and example links for readers and assistants; never an authority or permission grant.

A locally valid document is not proof of identity, permission, safe networking, or a working integration. The walkthrough and tests use synthetic files and do not contact peers.
